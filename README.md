# Social Media AI

A responsive social media management website built using HTML, CSS and JavaScript.

## Features

- Social media dashboard
- Create post button
- Posting schedule
- Best time to post
- Follower growth
- Audience growth
- AI content section
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- Docker
- Nginx

## Run

Open index.html in a browser.

## Docker

docker build -t social-media-ai .

docker run -p 8080:80 social-media-ai
